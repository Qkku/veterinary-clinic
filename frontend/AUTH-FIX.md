# Совместимость с исходным GroomingSalon.API
В архиве только frontend. Backend и БД не изменялись. Запускайте оригинальный backend Даши с профилем https (7084), затем npm ci и npm run dev. Если сервер работает только по HTTP 5125, создайте .env.local с VITE_API_URL=/api и VITE_BACKEND_TARGET=http://localhost:5125. Перезапустите Vite после изменения. Не переносите старый .env с другим адресом API.
Вход: Auth/login; только при 401 — Auth/groomer-login. Профиль проверяется через Auth/me либо GroomerCabinet/me. При 401/403 сессия закрывается с объяснением; другие ошибки дают повторить проверку. Роль определяется по серверному профилю, не по выбору пользователя.
Старый backend не содержит Reviews/all, Reviews/public, Reviews/{id}/moderate, LeaveRequests, Schedule/admin; эти функции новой админки не будут полностью работать без согласования API. Причина отмены не сохраняется отдельным полем в исходной БД. Эти ограничения не должны сбрасывать авторизацию. Сборка Vite и проверка с живым сервером не выполнены.
